# L'Écorchée

Une mygale à genoux rouges (*Brachypelma hamorii*) en 3D, à découper dans le navigateur : scalpel en long, en travers ou à plat, éclaté, et atlas de 98 parties anatomiques.

**Essayer :** https://brooly-cmd.github.io/l-ecorchee/

Démonstration, pas une référence scientifique : l'anatomie suit les grandes lignes connues, avec des formes simplifiées, sans relecture par un spécialiste.
