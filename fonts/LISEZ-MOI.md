# Polices de L’Écorchée

Les fichiers WOFF2 sont servis avec la démo, sans installation sur l’appareil ni appel à Google Fonts pendant la visite.

- **Bodoni Moda** — `bodoni-moda-italic-latin.woff2` : police variable, italique, graisses 400 à 900, caractères latins. Source : [Google Fonts](https://fonts.google.com/specimen/Bodoni+Moda). Copyright 2020 The Bodoni Moda Project Authors. Licence : [SIL Open Font License 1.1](https://github.com/google/fonts/blob/main/ofl/bodonimoda/OFL.txt).
- **Hanken Grotesk** — `hanken-grotesk-latin.woff2` : police variable, droite, graisses 100 à 900, caractères latins. Source : [Google Fonts](https://fonts.google.com/specimen/Hanken+Grotesk). Copyright 2021 The Hanken Grotesk Project Authors. Licence : [SIL Open Font License 1.1](https://github.com/google/fonts/blob/main/ofl/hankengrotesk/OFL.txt).

Les déclarations dans `../style.css` utilisent des chemins relatifs et `font-display:swap` pour afficher le texte pendant le chargement des polices.
